# ptyro logo

The burst of coloured agents around a terminal prompt. Use the dark set on dark or colourful
pages and the `-on-white` set on white or light ones (its logo has a solid white background).

<img src="ptyro-logo.png" alt="ptyro logo" width="480"> <img src="ptyro-icon.png" alt="ptyro icon" width="120">

<img src="ptyro-logo-on-white.png" alt="ptyro logo for white backgrounds" width="480"> <img src="ptyro-icon-on-white.png" alt="ptyro icon for white backgrounds" width="120">

`ptyro-logo` · `ptyro-icon` · `ptyro-logo-on-white` · `ptyro-icon-on-white`, each as `.svg` (1200×400 and 512×512) and `.png`.

The web app's favicon, PWA icons and apple-touch icon are rendered from `ptyro-icon.svg` by
`make icons` (needs `rsvg-convert`).
